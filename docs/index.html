Features

Snap windows without friction.

A small, native menu bar app that covers the layouts you use every day and nothing else.

Live snap preview

A translucent, blurred overlay shows the target frame while you drag. Release to snap, or release outside a zone and nothing happens.

Halves, quarters and thirds

Left and right edges make halves, corners make quarters, the top edge maximizes, and the bottom edge gives left, center or right thirds.

Global keyboard shortcuts

Control + Option with the arrow keys, U/I/J/K, D/F/G, Return and C. Control + Option + Delete restores the original size.

Tunable in Settings

Set edge sensitivity from 2 to 30 pt and a gap of 0 to 40 pt. Toggle drag-to-snap, shortcuts and launch at login, and ignore specific apps.

Multi-display aware

Windows snap on the screen under the pointer and respect its visible frame, so the menu bar and Dock are never covered.

Careful and private

Only a window's title bar starts a snap, and sheets and full-screen windows are skipped. There are no network requests, accounts or servers.

Install

Up and running in a minute.

EdgeSnapZones is open source and not notarized with a paid Apple Developer ID, so macOS needs one extra step the first time.

  1. Download EdgeSnapZones-macOS.zip and unzip it.
  2. Move EdgeSnapZones.app to your Applications folder.
  3. Clear the quarantine flag once, then right-click the app and choose Open:
    xattr -cr /Applications/EdgeSnapZones.app
  4. Grant Accessibility access to EdgeSnapZones in System Settings → Privacy Security → Accessibility so it can move and resize windows.

FAQ

Questions, answered.

Is EdgeSnapZones really free and open source?

Yes. It is released under the MIT license, has no dependencies, and the full source is on GitHub. If it saves you time you can support development through the Support button, but nothing is locked behind it.

What permissions does it need?

Only Accessibility, which macOS requires to find the window under the pointer and move or resize it. It does not ask for Screen Recording, Input Monitoring, Camera, Microphone or network access.

Where is my data stored?

Your preferences, such as edge sensitivity, gap size and the ignore list, are stored locally in the app's standard macOS settings on your Mac. Nothing is sent anywhere, and there are no accounts.

Why isn't the app notarized?

Notarization requires a paid Apple Developer account, which this free project does not have. Right-click the app and choose Open once to launch it, or build it yourself from source with Xcode.

Was this written by AI?

Yes. EdgeSnapZones was generated by Claude Code from a written spec as a clean-room reimplementation, with no code or assets from any commercial app. The full source is on GitHub under MIT, so you can read every line before you run it. It has had less human review than a hand-written app, so bug reports are welcome.
